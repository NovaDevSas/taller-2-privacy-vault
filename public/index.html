03 · Diseño

Cómo funciona

El modelo recibe tokens; Atlas guarda la relación para restaurar la respuesta.

01

El mensaje llega al backend

La interfaz llama a POST /api/secureChatGPT.

02

Se detectan y reemplazan datos

Regex busca nombres, correos y teléfonos. Cada coincidencia recibe un token único.

03

Atlas guarda el mapa

Token, dato original, tipo y sesión quedan en privacy_vault.mappings.

04

Gemini genera la respuesta

Se le pide conservar los tokens tal como están.

05

El backend restaura el texto

Los tokens de esa sesión vuelven a sus valores originales.

Salida

JSON sencillo

El backend devuelve original, ofuscado, respuesta de Gemini y respuesta restaurada.

Límite

Solo una PoC

Regex no garantiza detectar toda la información personal.
